01

Momentum-Preserving Wallrun & Traversal

The Challenge

Unreal's default collision physics kills kinetic energy on wall impact. Under jam time constraints, I needed wallrunning that preserved momentum and chained into jumps, without the complexity of a full custom movement state and its replicated physics overhead.

The Solution

I subclassed UCharacterMovementComponent and overrode OnMovementUpdated to run a wall scan every tick while IsFalling(). The character never leaves the standard falling state. Wallrun physics are applied as velocity corrections: a Dot Product validates wall angle, a Cross Product finds the forward tangent, and pre-impact speed from OldVelocity is forcefully restored.

Full Implementation (C++)

// --- 1. ENTRY & MEMORY CHECKS ---
FVector ViewDir  = CharacterOwner->GetControlRotation().Vector();
float   LookDot  = FVector::DotProduct(ViewDir, WallHit.Normal);
// Reject the attach if the camera is pointed too far away from the wall.
// (Tuned by feel: looser than a "look straight along the wall" check would be.)
bool bLookOK = LookDot < Stat_WallRunLookThreshold;

bool bIsNewWall = WallHit.GetComponent() != LastWallComponent;

if ((bSameWallWallrun || bIsNewWall) && bLookOK)
{
    // Capture "is this the first frame on the wall?" BEFORE flipping the flag,
    // otherwise the restore below can never run.
    bool bJustStarted = !bIsWallRunning;
    bIsWallRunning    = true;

    CurrentWallNormal = WallHit.Normal;
    LastWallComponent = WallHit.GetComponent();

    // --- 2. SEAMLESS MOMENTUM RESTORATION ---
    // Only on the entry frame: if the wall impact bled off speed, rebuild it
    // along the wall so the run feels like it "catches" rather than snags.
    if (bJustStarted)
    {
        float PreImpactSpeed  = OldVelocity.Size2D();
        float PostImpactSpeed = Velocity.Size2D();

        if (PostImpactSpeed < PreImpactSpeed)
        {
            FVector ForwardAlongWall = FVector::CrossProduct(CurrentWallNormal, FVector::UpVector);

            // Flip the tangent if it points against the way we were moving.
            if (FVector::DotProduct(ForwardAlongWall, OldVelocity) < 0.f)
            {
                ForwardAlongWall = -ForwardAlongWall;
            }

            Velocity = ForwardAlongWall * PreImpactSpeed;
        }
    }

    // --- 3. WALL ADHESION PHYSICS ---
    Velocity.Z = 0.f;                                              // cancel gravity while attached
    Velocity -= CurrentWallNormal * (Stat_WallStickForce * DeltaSeconds); // gentle inward pull to stay glued
}

// --- 4. ADDITIVE MOMENTUM CHAINING (DoJump Override) ---
if (bIsWallRunning)
{
    FVector FlatViewDir = CharacterOwner->GetControlRotation().Vector().GetSafeNormal2D();
    // Aim mostly where the player looks, biased slightly out from the wall so
    // the jump clears it instead of re-attaching.
    FVector JumpTrajectory = (FlatViewDir + (CurrentWallNormal * Stat_WallJumpOutwardBias)).GetSafeNormal();

    Velocity += JumpTrajectory * Stat_WallJumpSpeedBoost;
    WallRunCooldown = Stat_WallRunCooldown;   // brief lockout before we can re-attach
}
02

Data-Driven Slope Physics & Momentum Decay

The Challenge

Standard Unreal movement is static on inclines. Additionally, exceeding MaxWalkSpeed violently clamps velocity, killing flow. I needed level geometry to actively dictate pacing while keeping physics parameters data-driven.

The Solution

I wrote a state-aware Master Speed Manager. For slope physics, the system projects DownVector against FloorNormal. I built a "Soft Cap" system using FMath::FInterpConstantTo to allow excess momentum to naturally decay.

Implementation Breakdown (C++)

// --- MASTER SPEED & SLIDE MANAGER (runs every tick in OnMovementUpdated) ---

// --- 1. STATE -> TARGET SPEED LIMIT (the "floor" we decay down to) ---
bool  bIsSliding = IsCrouching();
float TargetLimit = Stat_GroundMaxSpeed;              // Default run (e.g. 600)
if      (bIsWallRunning)              TargetLimit = Stat_WallRunSpeed;   // e.g. 1200
else if (bIsSliding)                 TargetLimit = Stat_CrouchWalkSpeed; // e.g. 300
if (bIsHorseRiding && !IsFalling())  TargetLimit = Stat_HorseSpeed;

// --- 2. TERRAIN-AWARE SLOPE PHYSICS ---
float CurrentDecay = Stat_SoftCapDecayRate;
if (bIsSliding)
{
    FVector FloorNormal      = CurrentFloor.HitResult.Normal;
    FVector GravityDownSlope = FVector::VectorPlaneProject(FVector::DownVector, FloorNormal).GetSafeNormal();
    float   SlopeDot         = FVector::DotProduct(Velocity.GetSafeNormal(), GravityDownSlope);

    if (SlopeDot > 0.1f)        // DOWNHILL: steer force down the slope, frictionless
    {
        Velocity += GravityDownSlope * (Stat_SlideSlopeBoost * SlopeDot) * DeltaSeconds;
        CurrentDecay = 0.f;
    }
    else if (SlopeDot < -0.1f)  // UPHILL: heavy braking
    {
        CurrentDecay = Stat_SlideUphillBrake;
    }
    else                        // FLAT: light drag
    {
        CurrentDecay = Stat_SlideDecayRate;
    }
}

// --- 3. UNIVERSAL UPHILL ACCELERATION BOOST (scales with steepness) ---
float TargetAccel = Stat_GroundAcceleration;
if (!IsFalling() && VisualSlopeFactor < -0.05f)
{
    float HillBoost = FMath::GetMappedRangeValueClamped(
        FVector2D(-0.05f, -1.0f),   // slight incline -> vertical
        FVector2D( 1.0f,   3.0f),   // 1x -> 3x power
        VisualSlopeFactor);
    TargetAccel *= HillBoost;
}
MaxAcceleration = TargetAccel;

// --- 4. THE SOFT CAP: bleed excess speed down smoothly instead of hard-clamping ---
float CurrentSpeed = Velocity.Size2D();
if (CurrentSpeed > TargetLimit)
{
    float NewSpeedLimit  = FMath::FInterpConstantTo(CurrentSpeed, TargetLimit, DeltaSeconds, CurrentDecay);
    MaxWalkSpeed         = NewSpeedLimit;
    MaxWalkSpeedCrouched = NewSpeedLimit; // raise crouch cap so the slide can carry speed
}
else
{
    MaxWalkSpeed         = Stat_GroundMaxSpeed;
    MaxWalkSpeedCrouched = Stat_CrouchWalkSpeed;
}
03

Runtime Shape-Shifting & Spatial Validation

The Challenge

Dynamically modifying collision geometry is prone to bugs. Transforming into a larger horse entity inside tight corridors can push players out of bounds or crash the movement state.

The Solution

I wrote a predictive spatial validation system using OverlapBlockingTestByChannel. Transformations are safely denied if clearance is insufficient, and state sanitization prevents conflicting physics states.

Implementation Breakdown (C++)

// --- 1. THE SPATIAL VALIDATION CHECK ---
void AJKAInspCharacter::ToggleHorse(bool bNewState)
{
    if (bNewState && !MyMoveComp->bIsHorseRiding)
    {
        // --- STATE SANITIZATION: never grow the capsule from an airborne state ---
        // Summoning mid-air freezes the soft speed-cap until the player uncrouches.
        // Require solid ground before shape-shifting.
        if (MyMoveComp->IsFalling())
        {
            PlaySound(SummonFailSound);
            return;
        }

        // --- PREDICTIVE CLEARANCE: does the taller horse capsule actually fit? ---
        bool bHitCeiling = GetWorld()->OverlapBlockingTestByChannel(
            GetActorLocation() + FVector(0, 0, 105.f),
            FQuat::Identity,
            ECC_Visibility,
            FCollisionShape::MakeCapsule(42.f, 192.0f)   // test the shape we're about to become
        );

        if (bHitCeiling)
        {
            PlaySound(SummonFailSound);
            return;
        }

        // --- GROW, THEN KEEP THE FEET PLANTED ---
        // SetCapsuleHalfHeight grows around the CENTER (up AND down), so a naive
        // resize sinks the lower half into the floor -> fall-through on thin
        // platforms. Offset UP by the growth to hold the feet where they were.
        const float GrowAmount = 192.0f - GetCapsuleComponent()->GetUnscaledCapsuleHalfHeight();
        GetCapsuleComponent()->SetCapsuleHalfHeight(192.0f);
        AddActorWorldOffset(FVector(0, 0, GrowAmount), false, nullptr, ETeleportType::TeleportPhysics);

        MyMoveComp->SetHorseMode(true);
    }
    else if (!bNewState && MyMoveComp->bIsHorseRiding)
    {
        // --- THE REVERSION (mirror image: shrink around center, shift DOWN to stay planted) ---
        const float HeightDiff = GetCapsuleComponent()->GetUnscaledCapsuleHalfHeight() - 96.0f;
        GetCapsuleComponent()->SetCapsuleHalfHeight(96.0f);
        AddActorWorldOffset(FVector(0, 0, -HeightDiff), false, nullptr, ETeleportType::TeleportPhysics);
        MyMoveComp->SetHorseMode(false);
    }
}
