Current Work & Education

I teach Computer Science labs and practicals at Zhytomyr Ivan Franko State University, a part-time teaching load, and I'm a PhD candidate there. My research area is replication in game engines, the same problem space as the server-authoritative multiplayer I built into Project Horizon. Neither is a heavy load and my schedule is built around project work: I'm available now for contract work, part-time or full-time.

I spent over two years as a programmer on Project Horizon. Most of that work was taking systems that were never built to talk to each other, a survival framework and a stack of marketplace plugins, and making them behave like one game in networked multiplayer.

Approach to Development

Speedrunning is where I learned how to work. A run is constant on-the-fly problem solving: the route breaks, something doesn't behave the way it did last attempt, and you have to diagnose it and adapt while the clock is running. It also teaches you to measure instead of assume. That is how I debug: test against the real thing, not against what I think the code does. On the KCD save converter that meant hundreds of manual load tests, because actually running the game was the only check that told the truth.

Background & Interests

I don't speedrun competitively any more, but I still run a charity marathon once a year.
